# 部署与使用指南

适用版本：动态壁纸 · Live Canvas `1.2.0`。本指南中的「安装到 Codex」指通过 **Codex++** 给 Codex 桌面应用加载拓展。

## 安装前准备

1. 安装并确认可以打开 [Codex 桌面应用](https://developers.openai.com/codex/app/)。
2. 从 [Codex++ 官方 Releases](https://github.com/BigPizzaV3/CodexPlusPlus/releases) 下载适合系统的版本，按其官方说明安装。
3. 在 Codex++ 中启动 Codex。若 Codex 已独立运行且管理器显示「未挂载」，使用管理器提供的「重启并挂载」。先保存正在进行的工作。
4. 确认 Codex 页面中出现 Codex++ 的入口，并且拓展总开关、界面增强处于开启状态。

仅运行 `codex` 命令行、直接打开原版 Codex，或在浏览器中打开 `renderer.js`，都不能加载本拓展。无需把文件放进 `~/.codex/skills`，也不需要修改 `config.toml`、配置模型 Key 或接入拓展创作 MCP。

本项目已在 Windows 环境运行；macOS 安装路径来自 Codex++ 官方文档，未实机验证。Linux 不在本项目当前的已验证支持范围内。

## 社区安装

1. 打开 Codex++ 管理器的「拓展 → 社区拓展」。不同版本的页面也可能叫「万物皆拓展」。
2. 点击刷新，搜索 `codex-live-wallpaper` 或 `动态壁纸`。
3. 核对仓库为 `luojinghao/codex-live-wallpaper`，拓展 id 为 `live-wallpaper-studio`。
4. 审阅能力提示：本拓展含页面脚本和常驻后台，没有模型工具、钩子、网关中间件或定时后台任务。社区拓展未经官方审核。
5. 安装后进入「本地拓展」，启用「动态壁纸 · Live Canvas」。安装后默认不启用是正常行为。
6. 点击「热重载拓展」，回到由 Codex++ 挂载的 Codex 页面。

社区列表缓存可能延迟约 10 分钟；点击刷新后仍找不到时使用下面的手动安装方式。当前安装版本以管理器显示为准。

## 手动安装

### 1. 下载安装包

进入[本项目 Releases](https://github.com/luojinghao/codex-live-wallpaper/releases/latest)，下载附件：

```text
live-wallpaper-studio-v1.2.0.zip
```

优先下载这个拓展 ZIP，而不是 GitHub 自动生成的 `Source code`。附件根目录直接有 `codexpp.json`；源码压缩包通常还套有仓库名称目录。

### 2. 放入拓展目录

在 Codex++ 提供的打开拓展目录入口中查看实际路径；默认路径如下：

| 系统 | 拓展目录 |
| --- | --- |
| Windows | `%APPDATA%\Codex++\user_scripts\` |
| macOS | `~/.config/Codex++/user_scripts/` |

在该目录中新建 `live-wallpaper-studio` 文件夹，把 ZIP 的内容解压进去。最终结构必须是：

```text
user_scripts/
  live-wallpaper-studio/
    codexpp.json
    renderer.js
    backend/
      main.mjs
    README.md
    docs/
      使用指南.md
```

不要多套一层 `codex-live-wallpaper-main/` 或 `live-wallpaper-studio/`。加载器要能直接找到 `user_scripts/live-wallpaper-studio/codexpp.json`，不要只复制 `renderer.js` 而遗漏后台。

Windows 可在资源管理器地址栏输入 `%APPDATA%\Codex++\user_scripts` 打开目录；目录不存在时可手动新建。无需管理员权限。

### 3. 启用并确认

1. 打开 Codex++「本地拓展」，刷新列表。
2. 找到「动态壁纸 · Live Canvas」，打开它的开关与拓展总开关。
3. 点击「热重载拓展」。如果页面尚未连接，先通过 Codex++ 启动或挂载 Codex。
4. 确认该项为 `loaded` 或加载成功，且没有错误。
5. 回到 Codex，点击左侧图标栏的「动态壁纸」入口。首次启用通常会自动打开图库。

本拓展没有 Web 服务器，也没有需要填写的本机端口。正常部署不需要运行 `npm install`、`npm run dev` 或 `node backend/main.mjs`，后台由 Codex++ 自动启动。

## 打开与关闭

可任选一种方式打开右侧图库：

- 点击 Codex 左侧图标栏的「动态壁纸」图标。
- 在 Codex++ 菜单找到「动态壁纸图库」，点击「打开图库」。
- 在输入框输入 `/wallpaper` 并执行。
- Windows 使用 `Ctrl+Shift+W`，macOS 使用 `Command+Shift+W`；若与其他快捷键冲突，使用图标入口。

关闭右侧图库面板不会关闭背景。要恢复普通界面，点击面板里的「关闭壁纸」，或关闭 Codex++ 菜单中的「启用动态壁纸」。收藏与设置会保留。

## 选择在线壁纸

1. 打开「在线图库」。
2. 在「视频数据源」选择全部数据源或某个站点。
3. 在「内容分类」选择分类，或者点击自然风景、人文生活、城市建筑、抽象几何、动漫等快捷项。
4. 点击缩略图应用壁纸。首次应用需要下载媒体，等待状态从加载变为播放。
5. 点击星标收藏，用「上一页」「下一页」浏览结果。

默认聚合自然风景。Mixkit 主要是实拍和抽象素材，其他四个站点主要是动态壁纸；「风景」并不保证是实拍。不是每个站点都有全部分类，切换数据源后分类可能自动调整。

关键词建议使用英文，如 `forest`、`street`、`abstract`。提交关键词会切到「全部分类」，在所选数据源内搜索；重新选择分类会清空关键词。点击「重置」回到全部数据源和自然风景。

「部分源暂不可用」表示仍可使用其余源的结果。点击「重试」或切换数据源即可；网络故障时可能展示上次缓存。

## 画质与画面

展开「清晰度与画面适配」：

| 设置 | 作用 |
| --- | --- |
| 自动 | 尝试选择原站提供的 1080p 原版，必要时回退 |
| 预览 | 优先较小的预览资源，通常更快、更省流量 |
| 1080p / 2K / 4K | 仅在当前原站实际提供并可访问时有效，不会将低清视频超分辨率 |
| 完整显示 | 保留完整画面和原始比例，窗口比例不同时会留边 |
| 填充整窗 | 保持比例并裁切画面，可调主体横向和纵向位置 |
| 拉伸铺满 | 不留边，但可能变形 |
| 背景遮罩 | 越高越暗，便于阅读文字 |
| 背景模糊 | 只改变显示效果，不提升原视频清晰度 |
| 玻璃模糊 / 面板遮罩 | 调整 Codex 部分面板的透明与背景模糊效果 |

可先使用「清晰完整」预设。高清不可用时会提示回退预览；可点击「打开当前壁纸原站」，按原站条款下载后从本地导入。

在「画面与播放设置」中可调整播放速度和自动轮换间隔。自动轮换会参考收藏或当前结果；没有合适资源时可使用内置场景。窗口不可见时暂停默认开启，以降低负载。

管理器里的拓展设置用于默认值，面板里调整过的偏好会持久化并覆盖默认值；修改默认值不一定覆盖已有用户设置。

## 本地视频与直链

展开「导入本地视频 / 视频直链」：

1. 点击「选择视频 / GIF 文件」，选择 MP4、WebM、GIF、PNG、JPG 或 WebP；也可填写完整文件路径后点击「导入并记住」。
2. 导入完成后会进入「本地壁纸」，并复制一份到拓展专属媒体目录。原文件不会被移动、压缩或转码。
3. 本地单文件上限为 256 MB。请保证磁盘空间足够，视频能被 Codex 内置浏览器解码。
4. 也可填写以 `.mp4`、`.webm` 或受支持图片后缀结尾的 HTTP(S) 媒体直链，点击「应用直链」。网页地址、分享页、需登录的地址通常不能直接使用，优先使用可信 HTTPS 地址。

在线媒体单文件缓存上限为 180 MB，超出时请按许可从原站下载并本地导入。不支持的视频编码需要自行转换，拓展不转码。

「内置场景」中的雨幕、星空和代码之雨无需联网。首次应用时，若系统开启减少动态效果，需要点击「仍然播放」才会动。

## 更新与备份

社区安装优先使用管理器提供的更新功能。手动更新时先停用拓展，再用新版本覆盖 `live-wallpaper-studio` 内的发布文件，保持目录名与 id 不变，然后重新启用并热重载。

媒体和图库缓存的默认位置：

| 系统 | 数据目录 |
| --- | --- |
| Windows | `%APPDATA%\Codex++\extension-data\live-wallpaper-studio\` |
| macOS | `~/.config/Codex++/extension-data/live-wallpaper-studio/` |

`media/` 含下载和导入的媒体，`*.catalog.json` 是图库缓存。收藏、当前壁纸和偏好由 Codex++ 的隔离存储保存，不在安装 ZIP 中；仅备份 `media/` 并不是完整的收藏或设置备份。迁移前请关闭应用，按 Codex++ 的备份说明处理应用数据，并保留原始视频。

不要把整个 Codex++ 配置、会话目录、缓存或本地路径日志上传到公开仓库。

## 故障排查

| 现象 | 检查方法 |
| --- | --- |
| 原版 Codex 中没有入口 | 确认 Codex 由 Codex++ 启动或挂载，界面增强与拓展总开关已开启 |
| 本地拓展列表没有本项目 | 检查目录是否多套一层，`codexpp.json` 是否直接位于 `live-wallpaper-studio` 下 |
| 已安装但没有效果 | 社区安装默认不启用，先打开本地拓展开关，再热重载并查看加载错误 |
| `loaded` 但背景仍不显示 | 先应用内置场景，确认「启用动态壁纸」开启；检查是否与其他主题或透明背景拓展冲突 |
| 图库加载失败、HTTP 403 或验证码 | 原站可能限流、改版或限制地区，切换源、稍后重试或使用合法的本地媒体，不要绕过访问限制 |
| 第一次应用等待较长 | 正在下载媒体，先切预览或选择更小的视频；检查网络和磁盘空间 |
| 视频静止 | 检查暂停状态、窗口是否隐藏、系统减少动态效果；需要时点击「仍然播放」 |
| 高清设置后仍是预览 | 当前来源未提供或无法访问所选画质，查看回退提示并去原站确认 |
| 视频有黑边或主体被裁切 | 在完整显示和填充整窗之间切换，裁切模式可调主体位置 |
| 文件存在但无法播放 | 扩展名不代表解码器支持，先在系统播放器检查，再改用浏览器支持的编码版本 |
| 导入后提示本地缓存不存在 | 媒体缓存可能被清理，从原始文件重新导入 |
| Node / 后台启动报错 | 更新 Codex++，查看其日志与诊断；正常情况下使用 Codex 自带 Node，特殊环境按上游说明配置 `CODEX_PLUS_NODE` |
| 占用偏高 | 使用 1080p 或预览、关闭玻璃模糊与画面模糊、开启窗口不可见时暂停，或改用静态图片 |
| Codex 更新后透明效果异常 | 原生 DOM 结构可能变更，先停用本拓展恢复界面，再提交版本信息与复现步骤 |

反馈时请附上系统、Codex / Codex++ / 本拓展版本、数据源、错误文字和复现步骤。截图先裁掉对话、账号、文件路径和其他私人内容，不要上传完整配置或凭据。

## 停用与卸载

仅想临时关闭时，用面板「关闭壁纸」或菜单「启用动态壁纸」开关。

彻底卸载时，在 Codex++ 本地拓展中停用它，关闭相关应用后移除 `user_scripts/live-wallpaper-studio` 安装文件夹。需要释放缓存空间时，确认不再需要导入媒体，并备份原文件，再手动移除本拓展自己的 `extension-data/live-wallpaper-studio` 数据文件夹。

不要删除整个 `user_scripts`、`extension-data` 或 Codex++ 配置目录。移除数据缓存后，保留的收藏或本地壁纸引用可能需要重新导入。

## 素材与隐私

图库内容分别来自 [Mixkit](https://mixkit.co/free-stock-video/)、[MoeWalls](https://moewalls.com/)、[MotionBgs](https://motionbgs.com/)、[WallpaperWaifu](https://wallpaperwaifu.com/)、[LiveWallpapers4Free](https://livewallpapers4free.com/)，版权与使用许可归各自权利人。免费浏览不等于可以商用或再分发。原站素材许可、署名要求和访问条款始终优先。

本项目发布包不包含第三方视频、图片或整站网页快照。在线浏览会向相应网站发出正常的图库、缩略图和媒体请求，站点会看到网络请求信息。输入自定义直链会请求该地址，请勿使用不信任的服务。

当前代码不读取或上传 Codex 会话、不调用模型、不需要 API Key，也没有遥测服务；用户选择的文件会复制到本机缓存，而不是上传到远程服务器。不过常驻后台以你的用户权限运行，不是沙箱，安装前仍应检查源码和版本来源。
